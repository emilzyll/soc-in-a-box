# SOC in a Box

Домашняя лаборатория Security Operations Center: сбор логов, обнаружение угроз и автоматизация реагирования в одном проекте.

## Структура

- `docs/` — документация, схемы и инструкции по развёртыванию
- `journal/` — журнал работы: заметки, находки, разборы инцидентов
- `detections/` — правила обнаружения (Sigma, YARA, запросы к SIEM)
- `automation/` — скрипты и плейбуки для автоматизации

## Безопасность

Секреты и ключи хранятся в `.env`, который исключён из репозитория через `.gitignore`.
